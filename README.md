# skill

Codex 自定义技能。内置的 `.system` 技能没有放进来。

## codex

| 技能 | 用途 |
| --- | --- |
| [coding](codex/coding) | 写代码、改代码、重构、调试、测试和评审。简单改动走对话确认，复杂或高风险改动先出中文分析文档。 |
| [feature-development](codex/feature-development) | 新功能开发的上游流程。先确认是不是新功能、要不要拆模块，再交给 coding。 |
| [modular-feature-development](codex/modular-feature-development) | 按项目现有结构把新功能做成独立模块。 |
| [frontend-prototype-rebuild](codex/frontend-prototype-rebuild) | 按页面截图或原型还原前端静态页面。 |
| [pre-change-collaboration-check](codex/pre-change-collaboration-check) | 改已有代码前，检查工作区重叠改动和相关贡献者。 |
